# Ficha da Métrica M-01

* **Nome:** Cobertura de Testes Automatizados (Code Coverage)
* **Classificação:** Produto
* **Objetivo:** Garantir a confiabilidade e facilidade de manutenção das regras de negócio no backend (Spring Boot).
* **Fórmula / Definição:** 
  $$\text{Cobertura (\%)} = \left( \frac{\text{Linhas de Código Executadas por Testes}}{\text{Total de Linhas de Código Elegíveis}} \right) \times 100$$
* **Fonte dos Dados:** Relatório Jacoco gerado automaticamente no pipeline do GitHub Actions / Maven.
* **Frequência de Atualização:** A cada Pull Request e ao final de cada Sprint.
* **Responsável pelo Acompanhamento:** Ana Clara Teixeira Ronzani (Engenheira de Qualidade).

---

## Forma de Interpretação
* **Abaixo de 50%:** Crítico. Indica baixa confiabilidade e risco em refatorações. Exige escrita de testes antes da aprovação do PR.
* **Entre 50% e 69%:** Aceitável para fases iniciais do projeto, com necessidade de expansão das suítes de teste.
* **70% ou superior:** Ideal para a maturidade pretendida no MVP do ServiceHub.
